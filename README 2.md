# THE VAULT — Version 5 Final

Netlify-ready static deployment. Upload this folder or the ZIP directly to Netlify.

Included:
- White House Collections 001–004 with locally archived PDFs and searchable records
- Executive Orders live Federal Register loader
- Laws shelves and GovInfo links
- Judicial Vault framework for Supreme Court, appellate, and district-court records
- Search, timeline, record modal, and responsive layout

The Judicial Vault framework is intentionally preserved for later court-data population; it has not been removed.
